# Smilo 4k Titles

Batch 4K video upscaling and AI titles for Windows 10/11 x64.

## Download

Get the **installer** or **portable ZIP** from [Latest release](https://github.com/SmiloAI/smilo-4k-titles/releases/latest). Both include FFmpeg; Antigravity is downloaded separately from the app Settings or an existing signed-in installation is reused. Microsoft Edge WebView2 Runtime is required.

## Updates

In the app, open **Settings → Updates → Check for updates**. Download the newer installer, close the app, then run it. Saved settings, keys and your library remain in `%LOCALAPPDATA%\Smilo4kTitles`. Portable users can extract the full newer ZIP into a new folder; it uses the same saved data.

## Features

- Process one or many video folders, including subfolders.
- Preserve originals, with related 4K output folders.
- AI titles with model, title-style and retry settings.
- Built-in folder explorer and video preview.
- Light/dark themes and local CPU, GPU and RAM meters.
