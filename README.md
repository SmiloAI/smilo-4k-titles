# Smilo 4k Titles


Batch 4K video upscaling and AI titles for Windows 10/11 x64.


## Download


Download the **Windows installer** from [Latest release](https://github.com/SmiloAI/smilo-4k-titles/releases/latest). No GitHub account or sign-in is required.


The installer includes FFmpeg. Antigravity can be installed separately from Settings or an existing signed-in installation reused. Microsoft Edge WebView2 Runtime is required.


Only installers and release documentation are published here. The application source and portable ZIP stay on the owner’s PC.


## Updates


Open **Settings → Updates → Check for updates**. Updates use this official GitHub repository. Saved settings, keys and your library remain in `%LOCALAPPDATA%\Smilo4kTitles` when the installer upgrades the app.


## Features


- Process one or many video folders, including subfolders.
- Preserve originals; place 4K outputs in related folders.
- AI titles with model, title-style and retry settings.
- Built-in folder explorer and video preview.
- Light/dark themes and local CPU, GPU and RAM meters.
